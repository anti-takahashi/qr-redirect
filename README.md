# qr-redirect

アンティーク家具たかはしの **QRラベル中継**。公開先 `https://qr.antiquekagu-takahashi.com/`

印刷したQRのURLは二度と変えられない（ラベルは何年も貼りっぱなし）。
行き先を直接焼き込むと、その行き先が使えなくなった日にラベルが全部死ぬ。
→ **当社が握るドメインに、行き先を後から変えられる1枚を置く。**

- ラベルに焼くのは `https://qr.antiquekagu-takahashi.com/?t=<32桁16進>` **だけ**
- 行き先を変えるときは `index.html` の `TARGET` を直す
- ⚠️ **置き場（GitHub Pages）はいつでも変えてよい。変えてはいけないのはドメインの方**

秘密情報は入れない（公開リポジトリ）。
